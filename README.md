# Центр карьеры · Южный университет (ИУБиП)

Одностраничный портал карьерного центра: подборка вакансий и стажировок, конструктор
резюме, программы амбассадоров, карьерный трек, целевое обучение и аналитика выпуска.

> Редизайн: интерфейс, типографика и подача переработаны заново. Исходная версия —
> статический `index.html` с встроенными CSS и JS; здесь тот же функциональный состав,
> но на React с компонентами и данными, вынесенными в `src/data`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc && vite build
npm run preview
```

## Стек

- React 18 + TypeScript 5
- Vite 6, Tailwind CSS **v4** (`@tailwindcss/vite`, без `tailwind.config.js` — токены в `src/index.css`)
- `lucide-react` для иконок
- Без бэкенда, роутинга и внешних шрифтов: работает офлайн, собирается в статику

## Дизайн-система

Токены заданы в `src/index.css` и правятся в одном месте:

| Токен | Основная тема | Тёмная тема |
|---|---|---|
| `--navy` (фон бренда) | `#0e3324` тёмно-зелёный | `#000000` чёрный |
| `--azure` (действия) | `#1a7a4e` изумрудный | `#ffffff` белый |
| `--amber` (акценты, числа) | `#dfa92f` золото | `#ffffff` белый |
| `--surface` / `--card` | `#f3f7f2` / белый | `#0a0a0a` / `#121212` |
| `--radius-card` | `18px` | `20px` |

Имена переменных исторические и закреплены за готовыми утилитами разметки:
`bg-navy` — тёмно-зелёный, `bg-azure` — изумрудный, `bg-amber` — золото.

**Тёмная тема** включается кнопкой в шапке (луна/солнце), выбор запоминается в
`localStorage` (`ck-theme`), при первом заходе берётся системная.

**Боковое меню-кружок** (`MenuOrb`): в основной теме — тёмно-зелёный круг с
золотой шестерёнкой, в тёмной — белый кружок, из которого «каплей»
(`clip-path: circle()`) выезжают разделы.

Компонентные классы: `.panel` (карточка с тонкой рамкой), `.section-title` (заголовок с
янтарной чертой), `.metric` (крупное число), `.caption` (служебная подпись), `.nav-link`
(пункт меню с янтарным подчёркиванием активного).

Типографика: заголовки — серифный стек (Georgia/Times), интерфейс — системный sans.
Внешние шрифты не подключаются: сайт должен открываться без интернета.

## Данные

Вакансии лежат в `src/data/vacancies.ts`. Обновление подборки — задача отдельного
скрипта, который забирает данные с открытого API «Работы России» (trudvsem.ru) и правит
этот файл; на фронтенде никакой сети нет.

Форма обратного звонка и мастер резюме работают на клиенте: заявка собирается и
показывается подтверждением. Для реальной отправки подключите почтовый или CRM-эндпоинт
в `CallbackModal.submit` и в обработчике скачивания резюме.
